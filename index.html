Formulare automatisch auslesen

  1. console.anthropic.com öffnen und anmelden.
  2. Unter Billing einmalig Guthaben aufladen – 5 € reichen für mehrere tausend Formulare.
  3. Unter API Keys auf Create Key, den Schlüssel kopieren.
  4. Hier unten einfügen und speichern. Fertig.

Ohne Schlüssel funktioniert das Scannen weiterhin – die Felder werden dann von Hand eingetippt, während das Foto danebensteht.

Knöpfe in der Kopfleiste

Angehakt heißt: der Knopf steht oben in der Leiste. Alles andere bleibt über das Menü ☰ erreichbar. Die Auswahl gilt nur für dich – jeder richtet sich die Leiste so ein, wie er sie braucht.

Arbeitszeit

–

Die Stunden rechnet kub.ik selbst aus: Ende minus Beginn, abzüglich der Pause. In der Tabelle geht das auch direkt – einfach 7:30-15:30 in das Feld tippen.

Passwort vergessen

kub.ik schickt einen Link zum Zurücksetzen – aber nur an eine echte E-Mail-Adresse. Kurze Benutzernamen wie admin haben kein Postfach dahinter.

Für diesen Zugang ist keine E-Mail hinterlegt. Zwei Wege:

  1. Der Chef setzt das Passwort in der Supabase-Oberfläche neu: Authentication → Users, den Benutzer anklicken, Reset password.
  2. Damit es beim nächsten Mal von selbst geht: nach dem Anmelden unter Konto eine echte E-Mail-Adresse hinterlegen.

Neues Passwort setzen

Du bist über den Link aus der E-Mail hier gelandet. Vergib jetzt ein neues Passwort – danach bist du angemeldet.
